Publicador do canal

Ferramenta interna do canal @infinityCursosBeberibe no YouTube.

O que é

O canal publica, todo dia útil, uma aula narrada e Shorts de estudo para o concurso de Soldado da Polícia Militar de Pernambuco (PM-PE 2026). Os vídeos são gerados a partir de materiais de estudo próprios.

O "Publicador do canal" é o programa que envia esses vídeos ao YouTube pela API oficial (YouTube Data API v3). Ele é usado somente pelo dono do canal, para publicar no próprio canal. Não é oferecido a outras pessoas e não acessa contas de terceiros.

Material independente

Material de estudo independente e não oficial, sem vínculo com a Polícia Militar de Pernambuco, com o Governo do Estado de Pernambuco ou com a banca do concurso.
