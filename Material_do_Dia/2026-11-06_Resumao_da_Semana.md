## 1. O essencial — quinta, 05/11

### Figuras de linguagem (item 3)

| Figura | Marca para reconhecer |
|---|---|
| **Comparação** | Tem conectivo: *como, tal qual, feito, parece* |
| **Metáfora** | Aproxima dois elementos **sem** conectivo |
| **Prosopopeia** | Ser inanimado ou animal com ação ou sentimento humano |
| **Zeugma** | Um termo já dito fica subentendido |
| **Metonímia** | Troca por proximidade (autor pela obra, marca pelo produto, continente pelo conteúdo) |
| **Sinédoque** | Parte pelo todo, singular pelo plural |
| **Hipérbole / eufemismo** | Exagero / suavização |
| **Antítese / paradoxo** | Opostos lado a lado / opostos na mesma afirmação |

- Comparação ou metáfora? **Procure o conectivo.**
- Se a questão pede duas figuras "respectivamente", siga a **ordem** em que aparecem no trecho.

### Relações semânticas (item 4)

**Teste:** troque o conectivo por outro da mesma família. Se o sentido continua, a relação é a mesma.

| Relação | Família de conectivos |
|---|---|
| **Adversidade** (coordenada) | mas, porém, contudo, todavia, entretanto, no entanto |
| **Concessão** (subordinada) | embora, ainda que, mesmo que, apesar de, **conquanto**, "mesmo depois de" |
| **Causa** | porque, já que, visto que, uma vez que, **porquanto** |
| **Explicação** | pois (antes do verbo), porque, que — justifica uma ordem ou opinião |
| **Conclusão** | portanto, logo, por isso, assim, **destarte**, pois (depois do verbo) |
| **Condição** | se (= caso), caso, desde que, contanto que |
| **Finalidade** | para que, a fim de que, para + infinitivo |
| **Consequência** | tão / tanto / tal... que |

- **Sem conectivo** também há relação: o ponto e vírgula pode separar ideias opostas. Teste encaixando um "mas".
- **Adversativa x concessiva:** as duas opõem ideias. A adversativa é coordenada; a concessiva é subordinada (em geral com subjuntivo) e **não fica sozinha** sem a oração principal.
- **"Se"** só é condicional quando dá para trocar por **"caso"**. Em "se escondeu", "se trata", é pronome.
- **Reescrita:** além do sentido, confira a gramática. Exemplo de regência: na norma-padrão, *ir* pede **a** ("vou ao fórum", "foram à delegacia").

## 2. O essencial — sexta, 06/11

### Significação das palavras (item 17)

| Conceito | Em uma linha |
|---|---|
| **Sinônimo** | Mesmo sentido **naquele contexto**, não só no dicionário |
| **Antônimo** | Sentido oposto (prefixos de negação ajudam: *in-*, *des-*, *a-*) |
| **Parônimos** | Forma parecida, sentidos diferentes |
| **Homônimos** | Mesma pronúncia ou grafia, sentidos diferentes (*cessão / sessão / seção*) |
| **Polissemia** | Uma palavra com vários sentidos, decididos pelo contexto |
| **Denotação x conotação** | Literal x figurado |

**Prefixos que resolvem questão:** *inter-* = entre · *hiper-* = excesso · *octo-* = oito · *in-* = negação.

**Parônimos da rotina policial** (dificuldade registrada):

| Par | Sentidos |
|---|---|
| mandado / mandato | ordem judicial / período de exercício de um cargo |
| tráfico / tráfego | comércio ilegal / movimento de veículos |
| infringir / infligir | violar (uma norma) / aplicar (pena, castigo) |
| flagrante / fragrante | evidente, no ato / perfumado |
| delatar / dilatar | denunciar / alargar, adiar |
| descriminar / discriminar | tirar o caráter de crime / separar ou tratar com preconceito |
| eminente / iminente | importante / prestes a acontecer |
| ratificar / retificar | confirmar / corrigir |

**Locução verbal** (dificuldade recorrente — **prioridade**):

| Locução | O auxiliar acrescenta sentido? | Pode virar verbo simples sem perda? |
|---|---|---|
| *ir* + infinitivo | Não, só marca o futuro | **Sim** (vai sair = sairá) |
| *ter/haver* + particípio | Não, só marca o tempo composto | **Sim** (tinha saído = saíra) |
| *poder* + infinitivo | Possibilidade | Não |
| *dever* + infinitivo | Obrigação ou probabilidade | Não |
| *precisar* + infinitivo | Necessidade | Não |
| *costumar* + infinitivo | Hábito | Não |
| *voltar a* + infinitivo | Repetição | Não |
| *estar* + gerúndio | Ação em andamento | Não |

**Formação de palavras:** no sentido de "gastar, usar", o substantivo de *consumir* é **consumo**.

### Variação linguística (item 18)

| Tipo | Varia conforme |
|---|---|
| **Regional** (diatópica) | o lugar |
| **Social** (diastrática) | o grupo: idade, profissão, classe |
| **Situacional** (diafásica) | o grau de formalidade |
| **Histórica** (diacrônica) | o tempo |

- **Coloquial** = informal: gírias, "a gente", "tá", "pra" e **expressões populares** (frases feitas cujo sentido não é o literal).
- Nenhuma variedade é "errada": o critério é a **adequação** à situação. Tratar uma variedade como inferior é **preconceito linguístico**. Na redação da prova vale a norma-padrão.

## 3. Pegadinhas da semana

| A banca escreve… | O certo é… |
|---|---|
| Trecho com "como" apresentado como metáfora | Com conectivo é **comparação** |
| "Porquanto" como conectivo de oposição | *Porquanto* = **causa** |
| "Conquanto" como conclusão | *Conquanto* = **concessão**; conclusão é *destarte* |
| "Para que" como consecutiva | *Para que* = **finalidade**; consecutiva = *tão/tanto... que* |
| Reescrita só com a oração do "embora" | A concessiva é **subordinada**: precisa da oração principal |
| Reescrita com "ir em" um lugar | Na norma-padrão, *ir* **a** (ao, à, aos, às) |
| Locução com *poder/dever/precisar/costumar* trocada por verbo simples "sem mudar o sentido" | Só *ir* + infinitivo (e *ter/haver* + particípio) trocam sem perda |
| Sinônimo que vale no dicionário, mas não na frase | O sinônimo tem de servir **no contexto** |
| Par de sinônimos ou de parônimos oferecido como antônimos | Antônimo = sentido **oposto** |
| "A variedade coloquial é um erro" | É questão de **adequação**; chamar de erro é preconceito linguístico |

## Respostas do teste-relâmpago

1. A comparação usa conectivo (*como, tal qual, parece*); a metáfora aproxima sem conectivo.
2. Prosopopeia (personificação): o relógio "cochila", ação humana.
3. (a) causa; (b) concessão; (c) conclusão.
4. Finalidade (objetivo de sair cedo).
5. Consequência (oração consecutiva: *tanto... que*).
6. "O sargento estava cansado, **mas** (porém, contudo...) terminou o relatório."
7. (b), porque dá para trocar por "caso": "Caso haja testemunhas...". Em (a), *se* é pronome.
8. "Vou registrar" = **registrarei**. Em "devo" (obrigação) e "costumo" (hábito), o auxiliar acrescenta sentido.
9. (a) repetição; (b) ação em andamento.
10. **mandado** (ordem judicial); **tráfego** (movimento de veículos).
11. **infringe** (viola a norma). *Infligir* é aplicar pena ou castigo.
12. Variação **regional** (diatópica): *jerimum* é mais usado no Nordeste.
13. "A gente" (no lugar de "nós") e "furou" (no sentido de faltar ao compromisso).
14. Duradouro, permanente, perene.
15. Sublinha a palavra "incorreta" e procura a alternativa **errada**, conferindo cada uma.
