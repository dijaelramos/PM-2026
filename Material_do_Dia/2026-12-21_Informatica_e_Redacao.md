## 1. Arquivos, pastas, extensões e caminhos

### 🟢 Iniciante — entender

Um **arquivo** é um conjunto de dados com nome (um texto, uma foto, um programa). Uma **pasta** (diretório) guarda arquivos e outras pastas. A **extensão** é o final do nome, depois do ponto, e indica o **tipo** do arquivo e o programa que o abre.

> **Ex. 1** *(criado pelo tutor)* — Em "relatorio_ocorrencia.**pdf**", a extensão **.pdf** indica um documento PDF.

### 🟡 Intermediário — aplicar

| Tipo | Extensões comuns |
|---|---|
| Texto | **.docx** (Word), **.odt** (Writer), **.txt**, **.pdf** |
| Planilha | **.xlsx** (Excel), **.ods** (Calc) |
| Apresentação | **.pptx** (PowerPoint), **.odp** (Impress) |
| Imagem | **.jpg**, **.png**, **.gif**, **.bmp**, **.tif**, **.svg** |
| Áudio | **.mp3**, **.wav**, **.wma** |
| Vídeo | **.mp4**, **.avi**, **.wmv**, **.mov**, **.mkv** |
| Compactado | **.zip**, **.rar**, **.7z** |
| Executável | **.exe** |

**Nomes:** não podem ter os caracteres **\ / : * ? " < > |**.
**Caminho:** o endereço do arquivo. Exemplo: **C:\Usuários\Ana\Documentos\escala.xlsx** (unidade C:, pastas separadas por **\**).

> **Ex. 2** *(criado pelo tutor)* — "Escala: dezembro.xlsx" **não** pode ser usado como nome, porque tem **dois-pontos**. "Escala - dezembro.xlsx" pode.

### 🔴 Avançado — acertar a prova

- **Imagem vetorial** (**.svg**) **não perde qualidade** ao ampliar, porque é desenhada por fórmulas. As imagens de pixels (**.jpg, .png, .gif, .bmp, .tif**) "estouram" ao ampliar *(consenso dos manuais)*.
- **.mp3** é **áudio**, não vídeo. **.jpg** é imagem. **.pptx** é apresentação.
- O Windows pode **ocultar as extensões** conhecidas (opção em Exibir); o arquivo continua tendo extensão.

> **Ex. 3 — contraexemplo** *(criado pelo tutor)* — "Toda extensão terminada em 'x' é vídeo." **Errado**: **.docx**, **.xlsx** e **.pptx** são do Office.

**Para levar para a prova:** extensão = **tipo** do arquivo. Vídeo: **mp4, avi, wmv, mov, mkv**; áudio: **mp3, wav**; imagem: **jpg, png, gif, bmp, tif**; vetorial que não perde qualidade: **svg**. Nomes não aceitam **\ / : * ? " < > |**.

## 2. Gerenciar arquivos e pastas no Explorador de Arquivos

### 🟢 Iniciante — entender

O **Explorador de Arquivos** é o programa do Windows para ver e organizar arquivos e pastas. Abre com **Windows + E**. Nele você cria, renomeia, copia, move e exclui.

> **Ex. 1** *(criado pelo tutor)* — Para criar uma pasta "Escalas 2027" em Documentos: abra Documentos, clique em **Novo > Pasta** (ou **Ctrl + Shift + N**) e digite o nome.

### 🟡 Intermediário — aplicar

| Ação | Como fazer |
|---|---|
| **Nova pasta** | **Ctrl + Shift + N** (ou botão Novo) |
| **Renomear** | **F2** |
| **Copiar** (fica nos dois lugares) | **Ctrl + C** na origem e **Ctrl + V** no destino |
| **Mover** (sai da origem) | **Ctrl + X** (recortar) na origem e **Ctrl + V** no destino |
| **Excluir** (vai para a Lixeira) | **Delete** (ou **Ctrl + D**) |
| **Excluir permanentemente** (sem Lixeira) | **Shift + Delete** |
| **Propriedades** | **Alt + Enter** |
| **Selecionar tudo** | **Ctrl + A** |
| **Desfazer** | **Ctrl + Z** |
| **Nova guia** do Explorador (Windows 11) | **Ctrl + T** |

**Arrastar com o mouse:**
- Na **mesma unidade** (C: para C:): **move**.
- Para **outra unidade** (C: para o pen drive): **copia**.
- Com **Ctrl**: **copia**; com **Shift**: **move**; com **Alt**: cria **atalho**.

**Lixeira:** guarda o que foi excluído do disco do computador, permitindo **restaurar**. O que é apagado de **pen drive** ou de **pasta de rede** **não** vai para a Lixeira.

> **Ex. 2** *(criado pelo tutor)* — Você arrasta um arquivo da Área de Trabalho para um pen drive. O arquivo é **copiado** (unidades diferentes): continua na Área de Trabalho.

> **Ex. 3** *(criado pelo tutor)* — Você excluiu sem querer, com Delete, uma planilha da pasta Documentos. Abra a **Lixeira**, clique com o botão direito no arquivo e escolha **Restaurar**.

### 🔴 Avançado — acertar a prova

- **Ctrl + X** marca para mover; o arquivo só sai da origem quando você **cola** (Ctrl + V) no destino.
- **Shift + Delete** e exclusão em **pen drive** não passam pela Lixeira.
- **Arrastar** muda de comportamento conforme a **unidade** de destino. Na dúvida, segure **Ctrl** (copiar) ou **Shift** (mover).
- **Atalho** (ícone com setinha) é só um **apontador**: apagar o atalho **não** apaga o arquivo original.

> **Ex. 4 — contraexemplo** *(criado pelo tutor)* — "Para mover, use Ctrl + C na origem e Ctrl + X no destino." **Errado**: Ctrl + C **copia**; Ctrl + X **recorta**; no destino, sempre **Ctrl + V**.

> **Ex. 5 — contraexemplo** *(criado pelo tutor)* — "O arquivo apagado do pen drive pode ser recuperado na Lixeira do computador." **Errado**: arquivos de **unidades removíveis** não vão para a Lixeira.

**Para levar para a prova:** nova pasta **Ctrl+Shift+N**; renomear **F2**; copiar **Ctrl+C → Ctrl+V**; mover **Ctrl+X → Ctrl+V**; excluir **Delete** (Lixeira); excluir permanente **Shift+Delete**; propriedades **Alt+Enter**. Arrastar: mesma unidade **move**, outra unidade **copia**; **Ctrl** copia, **Shift** move, **Alt** cria atalho.

## 3. Windows 11: interface e atalhos

### 🟢 Iniciante — entender

No Windows 11, o **menu Iniciar** e os ícones da **Barra de Tarefas** ficam **centralizados**. A **tecla do logotipo do Windows** (⊞), combinada com outras, dá acesso rápido a quase tudo.

> **Ex. 1** *(criado pelo tutor)* — Saindo de perto do computador do quartel, pressione **Windows + L** para **bloquear** a sessão.

### 🟡 Intermediário — aplicar

| Atalho (tecla Windows +) | Função (lista oficial da Microsoft) |
|---|---|
| **E** | Abrir o **Explorador de Arquivos** |
| **D** | Mostrar e ocultar a **área de trabalho** |
| **M** | **Minimizar todas** as janelas |
| **Shift + M** | Restaurar as janelas minimizadas |
| **L** | **Bloquear** o computador |
| **I** | Abrir **Configurações** |
| **R** | Abrir **Executar** |
| **S** | Abrir a **pesquisa** |
| **V** | Histórico da **área de transferência** |
| **X** | Menu **Link Rápido** (o mesmo do clique direito no Iniciar) |
| **F** | Abrir o **Hub de Comentários** |
| **Shift + S** | **Captura** de parte da tela *(base do curso)* |

| Outros atalhos | Função |
|---|---|
| **Alt + Tab** | Alternar entre janelas abertas |
| **Alt + F4** | Fechar a janela ativa |
| **Ctrl + Shift + Esc** | Abrir o **Gerenciador de Tarefas** |
| **Ctrl + Alt + Del** | Tela de segurança (bloquear, trocar usuário, sair, Gerenciador de Tarefas) |
| **F3** (no Explorador) | Procurar arquivo ou pasta |

> **Ex. 2** *(criado pelo tutor)* — Um programa travou e não fecha. Abra o **Gerenciador de Tarefas** (**Ctrl + Shift + Esc**), selecione o programa e clique em **Finalizar tarefa**.

### 🔴 Avançado — acertar a prova

- A banca cita a **versão**: atalhos podem **mudar** entre versões. No Windows 7, Windows + F procurava arquivos; no **Windows 11**, abre o **Hub de Comentários**. Para pesquisar, use **Windows + S** (ou **F3** no Explorador).
- **Windows + D** mostra a área de trabalho (e volta); **Windows + M** minimiza tudo (volta com **Windows + Shift + M**).
- **Snap** (layouts de janelas): novidade do Windows 11 para organizar janelas lado a lado.

> **Ex. 3 — contraexemplo** *(criado pelo tutor)* — "No Windows 11, Windows + L abre o Explorador de Arquivos." **Errado**: **L** = bloquear (**L**ock); **E** = **E**xplorador.

**Para levar para a prova:** **Win+E** Explorador; **Win+D** área de trabalho; **Win+M** minimizar tudo; **Win+L** bloquear; **Win+I** Configurações; **Win+R** Executar; **Win+S** pesquisa; **Win+V** área de transferência; **Ctrl+Shift+Esc** Gerenciador de Tarefas; **Alt+Tab** alternar; **Alt+F4** fechar.

## 4. Configurações, Painel de Controle e recursos do sistema

### 🟢 Iniciante — entender

O Windows 11 tem dois lugares para ajustes: o aplicativo **Configurações** (novo, **Windows + I**) e o **Painel de Controle** (antigo, ainda existe). A maioria das opções migrou para Configurações.

> **Ex. 1** *(criado pelo tutor)* — Para conectar fones Bluetooth: **Configurações > Bluetooth e dispositivos**.

### 🟡 Intermediário — aplicar

| Recurso | Para que serve |
|---|---|
| **Configurações** (Win + I) | Sistema, Bluetooth e dispositivos, Rede e Internet, Personalização, Aplicativos, Contas, Hora e idioma, Privacidade e segurança, **Windows Update** |
| **Painel de Controle** | Abre com **Win + R**, digitando **control**; ainda reúne opções antigas (programas e recursos, contas, dispositivos) |
| **Segurança do Windows** | Proteção nativa, com **antivírus** (Microsoft Defender) e firewall |
| **Windows Update** | Atualizações do sistema |
| **Gerenciador de Tarefas** | Processos, desempenho, aplicativos de inicialização; **finalizar tarefa** |
| **Compactação** | O Windows cria pastas compactadas **.zip** nativamente (botão direito > Compactar) |
| **Compartilhamento de pasta** | Permissões: **Leitura** (ver e abrir, sem alterar ou excluir) ou **Leitura/Gravação** (alterar e excluir) *(consenso dos manuais)* |
| **Desinstalar programa** | Configurações > **Aplicativos** > Aplicativos instalados (ou Painel de Controle > Programas e Recursos) |

> **Ex. 2** *(criado pelo tutor)* — Você quer que os colegas vejam a pasta "Normas", mas sem alterar nada. Compartilhe com permissão de **Leitura**.

### 🔴 Avançado — acertar a prova

- **Painel de Controle ainda existe** no Windows 11; não foi extinto.
- **Leitura** = só ver; **Leitura/Gravação** = ver, alterar e excluir. Para impedir mudanças, **Leitura**.
- **Antivírus nativo** = Microsoft Defender, dentro da **Segurança do Windows**.

> **Ex. 3 — contraexemplo** *(criado pelo tutor)* — "O Windows 11 eliminou o Painel de Controle." **Errado**: ele continua disponível (por exemplo, Win + R e **control**).

**Para levar para a prova:** **Configurações** (Win + I) é o centro de ajustes; **Painel de Controle** ainda existe (**control**); **Segurança do Windows** = antivírus e firewall; **Gerenciador de Tarefas** (Ctrl+Shift+Esc) finaliza programas; **.zip** nativo; compartilhar só para ver = **Leitura**.

## 5. Prompt de Comando

### 🟢 Iniciante — entender

O **Prompt de Comando** (cmd) é uma janela em que você digita **comandos de texto** em vez de clicar. Abre pela pesquisa (digite "cmd") ou por **Win + R** > **cmd**.

> **Ex. 1** *(criado pelo tutor)* — Digitar **dir** e Enter lista os arquivos e as pastas da pasta atual.

### 🟡 Intermediário — aplicar

| Comando | Função |
|---|---|
| **dir** | Lista arquivos e pastas |
| **cd** pasta | **Entra** numa pasta; **cd ..** volta um nível |
| **md** (ou mkdir) | **Cria** pasta |
| **rd** (ou rmdir) | **Remove** pasta |
| **copy** | Copia arquivos |
| **move** | Move arquivos |
| **del** | Apaga arquivos |
| **ren** | Renomeia arquivos |
| **cls** | Limpa a tela *(consenso dos manuais)* |
| **ipconfig** | Mostra a configuração de rede (endereço IP) *(base do curso)* |

> **Ex. 2** *(criado pelo tutor, resolvido)* — Criar a pasta "relatorios" e entrar nela:
> 1. **md relatorios**
> 2. **cd relatorios**

### 🔴 Avançado — acertar a prova

- **md/mkdir** cria; **rd/rmdir** remove **pasta**; **del** apaga **arquivo**.
- **cd ..** sobe um nível; **cd \\** vai à raiz da unidade *(consenso dos manuais)*.
- **ren** renomeia (no Explorador, o equivalente é **F2**).

> **Ex. 3 — contraexemplo** *(criado pelo tutor)* — "O comando del remove pastas no Prompt." **Errado**: para pasta, **rd** (rmdir); **del** apaga arquivos.

**Para levar para a prova:** **dir** lista; **cd** entra (**cd ..** volta); **md** cria pasta; **rd** remove pasta; **copy, move, del, ren** = copiar, mover, apagar e renomear arquivos; **ipconfig** = rede.

## 6. Quadros para não confundir

### 6.1 Copiar × mover

| | Copiar | Mover |
|---|---|---|
| Teclado | Ctrl + **C** → Ctrl + V | Ctrl + **X** → Ctrl + V |
| Arrastar | Para **outra unidade**, ou com **Ctrl** | Na **mesma unidade**, ou com **Shift** |
| Prompt | **copy** | **move** |
| Resultado | Arquivo nos **dois** lugares | Arquivo **só no destino** |

### 6.2 Excluir

| Ação | Vai para a Lixeira? |
|---|---|
| **Delete** num arquivo do disco | **Sim** |
| **Shift + Delete** | **Não** (permanente) |
| Excluir de **pen drive** ou **pasta de rede** | **Não** |
| **del** no Prompt | **Não** |
