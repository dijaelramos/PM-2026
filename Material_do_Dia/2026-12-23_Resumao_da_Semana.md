## 1. Windows 11: arquivos, pastas e sistema (21/12)

- **Extensões:** vídeo (.mp4, .avi, .mov, .wmv), áudio (.mp3, .wav), imagem (.jpg, .png, .gif; **.svg** é vetorial e não perde qualidade ao ampliar). Nome de arquivo **não** aceita \\ / : * ? " < > |.
- **Copiar** = Ctrl + C → Ctrl + V. **Mover** = Ctrl + **X** → Ctrl + V. Arrastar na **mesma unidade** move; para **outra unidade** (pen drive), copia.
- **Lixeira:** Delete manda para a Lixeira; **Shift + Delete**, pen drive, pasta de rede e o comando **del** excluem **sem** Lixeira. Apagar um **atalho** não apaga o arquivo.

| Tecla Windows + | Função |
|---|---|
| **E** | Explorador de Arquivos |
| **D** | Mostrar a área de trabalho |
| **M** | Minimizar tudo (Shift + M restaura) |
| **L** | Bloquear |
| **I** | Configurações |
| **R** / **S** / **V** | Executar / pesquisa / histórico da área de transferência |
| **F** | **Hub de Comentários** (no Windows 11 não é mais a pesquisa) |

- **Ctrl + Shift + Esc** = Gerenciador de Tarefas. **Painel de Controle** ainda existe (Win + R → **control**). Compartilhar só para ver = permissão de **Leitura**.
- **Prompt:** **dir** lista; **cd** entra (**cd ..** sobe); **md** cria pasta; **rd** remove pasta; **copy, move, del, ren**; **ipconfig** mostra a rede.

## 2. Raciocínio Lógico — revisão do item 1 (22/12)

- **Proposição** = declarativa com valor V ou F (frase falsa **é** proposição; pergunta, ordem, exclamação e sentença aberta não são). Linhas da tabela = **2ⁿ**.
- **Condicional** só é F em **V → F**: antecedente falso deixa o "se" **verdadeiro**.
- **Tautologia** (sempre V, como p ∨ ~p) · **contradição** (sempre F, como p ∧ ~p) · **contingência** (depende).

| "Se p, então q" | Forma | Dica |
|---|---|---|
| Equivalente | **~q → ~p** | Inverte, nega, **mantém o "se"** |
| Equivalente | **~p ∨ q** | "Não p **ou** q" (volta: nega a 1ª e põe "se") |
| **Negação** | **p ∧ ~q** | MANÉ: mantém, "e", nega. **Nunca começa com "se"** |

| Negar… | Resultado |
|---|---|
| p e q | ~p ou ~q |
| p ou q | ~p e ~q |
| ou p ou q | p se e somente se q |
| se (p e q), então r | p e q **e** ~r (antecedente **intacto**) |
| Todo A é B | Algum A **não** é B |
| Algum A é B / "é falso que algum A é B" | **Nenhum** A é B (predicado **mantido**) |

- **Falácias:** **afirmar o consequente** (p → q; q; logo p) e **negar o antecedente** (p → q; ~p; logo ~q). Válidos: *modus ponens* e *modus tollens*.

## 3. Word 2019 e Writer 7 (23/12)

| Recurso | Word 2019 | Writer 7 |
|---|---|---|
| Orientação | Layout → Orientação | **Formatar → Estilo de página → Página** |
| Quebra de página | **Ctrl + Enter** | **Ctrl + Enter**; Inserir → Mais quebras → **Quebra manual** |
| Mala direta | Guia **Correspondências** (Inserir Campo de Mesclagem) | Ferramentas → Assistente de mala direta |
| Sumário | Referências → Sumário | Inserir → Sumário e índice |
| Macros | Exibir → Macros (arquivo **.docm**) | Ferramentas → Macros |
| PDF | Arquivo → **Exportar** | Arquivo → **Exportar como** |
| Formato padrão | **.docx** | **.odt** (ODF: .ods planilha, .odp apresentação) |

| Tecla | Word (pt-BR) | Writer |
|---|---|---|
| Ctrl + **B** | **Salvar** | **Negrito** |
| Ctrl + **N** | **Negrito** | **Novo** |
| Ctrl + **S** | **Sublinhado** | **Salvar** |
| Ctrl + **T** / Ctrl + **A** | **Selecionar tudo** / Abrir | Ctrl + **A** = selecionar tudo |

- **Âncoras do Writer:** **na página, no parágrafo, no caractere, como caractere** (só essas).
- **Classificar** (Word) ordena **parágrafos** e **linhas de tabela**, não palavras dentro do parágrafo.
- **Macro** = série de comandos executada como **um só**, para automatizar tarefas.
