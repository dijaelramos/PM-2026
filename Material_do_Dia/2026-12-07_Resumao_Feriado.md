## 1. Raciocínio Lógico (07/12): diagramas lógicos

- **∈** liga **elemento** a conjunto; **⊂** liga **conjunto** a conjunto. **{2} ≠ 2**: um elemento pode ser ele mesmo um conjunto. **{∅}** é unitário.
- Um conjunto com *n* elementos tem **2ⁿ** subconjuntos.
- **Operações:**
  - **∪** = "ou" (junta);
  - **∩** = "e" (o que é comum);
  - **A − B** = o que é só de A (a ordem importa);
  - **complementar** = o que fica fora, dentro do universo.
- **n(A ∪ B) = n(A) + n(B) − n(A ∩ B).**
- **Dois conjuntos, de dentro para fora:** interseção → só A e só B → nenhum. "Somente A" exclui a interseção.
  - Quando o total é menor que a soma, a diferença é a interseção, desde que todos estejam em pelo menos um conjunto.
- **Três conjuntos, do centro para fora:**
  1. centro;
  2. pétalas (cada par menos o centro);
  3. bordas (cada conjunto menos as suas pétalas e o centro);
  4. fora.
  
  Confira se a soma das regiões dá o total.
- **Participações:** se cada pessoa está em 1, 2 ou 3 grupos, some os tamanhos dos grupos e monte as equações.
- **Tabela de dupla entrada:** para duas características do tipo sim/não, preencha o que falta em cada linha e coluna e confira os totais.
- **Conjuntos numéricos:** ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ. Os irracionais são decimais infinitos não periódicos. **ℚ − ℤ** são as frações cujo quociente não é inteiro (positivas ou negativas). Use √2 ≈ 1,41.
- **Probabilidade simples** (antecipação do item 4) = casos favoráveis ÷ total.

| O enunciado diz… | Região |
|---|---|
| pelo menos um / A ou B | união |
| os dois / A e B | interseção |
| somente A | A sem a interseção |
| exatamente um | só A + só B |
| nenhum | fora |
