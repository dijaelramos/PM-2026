## 1. Regência, colocação e revisão de LP (01 e 02/02)

| Tema | Lembrete |
|---|---|
| Assistir | Ver: **a** ("assistir **ao** jogo"); ajudar: direto ("assistir **o** ferido") |
| Aspirar / visar | Desejar / ter como objetivo: **a**; inalar / mirar: direto |
| Preferir | Algo **a** outra coisa (nunca "mais… do que") |
| Implicar (acarretar) | Direto: "implica **punição**" |
| Proceder (realizar) | **a**: "procedeu **à** análise" |
| Esquecer / lembrar | "Esqueci **o**…" ou "Esqueci-**me do**…" |
| Próclise | Com palavra atrativa (não, que, advérbio, indefinido, conjunção subordinativa) |
| Ênclise | Início de frase e imperativo afirmativo; **nunca** com futuro e particípio |
| Mesóclise | Futuro do presente/pretérito sem atrativa ("entregar-lhe-ei") |
| Crase | Facultativa antes de possessivo feminino; proibida antes de verbo e masculino |
| Método LP | Comando primeiro; reescrita = sentido **e** gramática; referência = troque e confira |

## 2. Raciocínio Lógico integrado (03/02)

| Tema | Lembrete |
|---|---|
| p → q | Falso só em **V → F**; equivale a **~q → ~p** e a **~p ∨ q**; negação: **p ∧ ~q** |
| De Morgan | ~(p ∧ q) = ~p ∨ ~q; ~(p ∨ q) = ~p ∧ ~q |
| Quantificadores | Negação de "todo" = "algum… não"; de "nenhum" = "algum" |
| Argumentos | Ponens e tollens válidos; afirmar o consequente e negar o antecedente são **falácias** |
| Hipóteses × evento que não ocorreu | **Pelo menos uma** hipótese é falsa |
| Verdades e mentiras | Teste cada hipótese; descarte a que gera contradição |
| Contagem | Multiplica; arranjo (ordem importa) × combinação; "pelo menos um" = 1 − nenhum |

| Quais | **MP, Advocacia Pública, Advocacia, Defensoria** (o TCU **não**) |

| Advogado | Indispensável; inviolável **nos limites da lei** |
| Defensoria | Mesmos princípios do MP; inamovibilidade; autonomia funcional e administrativa |
